# doberman-agent

Open-source enterprise Agent platform for conversations, multi-step tasks, workflows, knowledge retrieval and hosted applications.

[简体中文](README.md) · [English](README_EN.md) · [日本語](README_JPN.md) · [Español](README_ES.md) · [Português](README_PT.md) · [Русский](README_RU.md)

## Development and deployment

```bash
git clone https://github.com/cp7553479/doberman-agent.git
cd doberman-agent/src/frontend
pnpm install --frozen-lockfile
pnpm build
```

Requires Node.js 20.19+, pnpm 9, Python 3.11 and uv. See the component AGENTS.md files for development commands.
