# doberman-agent

Открытая корпоративная Agent-платформа для диалогов, многошаговых задач, рабочих процессов, поиска по базе знаний и размещения приложений.

[简体中文](README.md) · [English](README_EN.md) · [日本語](README_JPN.md) · [Español](README_ES.md) · [Português](README_PT.md) · [Русский](README_RU.md)

## Разработка и развёртывание

```bash
git clone https://github.com/cp7553479/doberman-agent.git
cd doberman-agent/src/frontend
pnpm install --frozen-lockfile
pnpm build
```

Требуются Node.js 20.19+, pnpm 9, Python 3.11 и uv. Команды разработки приведены в AGENTS.md соответствующих компонентов.
