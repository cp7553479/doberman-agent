# doberman-agent

Plataforma Agent empresarial de código aberto para conversas, tarefas com várias etapas, fluxos de trabalho, recuperação de conhecimento e hospedagem de aplicativos.

[简体中文](README.md) · [English](README_EN.md) · [日本語](README_JPN.md) · [Español](README_ES.md) · [Português](README_PT.md) · [Русский](README_RU.md)

## Desenvolvimento e implantação

```bash
git clone https://github.com/cp7553479/doberman-agent.git
cd doberman-agent/src/frontend
pnpm install --frozen-lockfile
pnpm build
```

Requer Node.js 20.19+, pnpm 9, Python 3.11 e uv. Consulte os arquivos AGENTS.md de cada componente para os comandos de desenvolvimento.
