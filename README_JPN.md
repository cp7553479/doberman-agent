# doberman-agent

対話、複数ステップのタスク、ワークフロー、ナレッジ検索、アプリケーションホスティングを提供する、セルフホスト可能なオープンソースの企業向け Agent プラットフォームです。

[简体中文](README.md) · [English](README_EN.md) · [日本語](README_JPN.md) · [Español](README_ES.md) · [Português](README_PT.md) · [Русский](README_RU.md)

## 開発とデプロイ

```bash
git clone https://github.com/cp7553479/doberman-agent.git
cd doberman-agent/src/frontend
pnpm install --frozen-lockfile
pnpm build
```

Node.js 20.19+、pnpm 9、Python 3.11、uv を使用します。開発コマンドは各コンポーネントの AGENTS.md を参照してください。

[ドキュメント](docs/README.md) · [Docker デプロイ](docker/README.md)
